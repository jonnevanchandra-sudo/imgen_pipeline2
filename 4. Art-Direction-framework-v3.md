# Art Direction Framework

## Purpose

Art Direction translates emotional meaning into visual interpretation.

Art Direction determines: What visual concept should exist psychologically?

NOT: How the feeling is technically rendered

Art Direction does NOT determine:

- rendering execution
- composition execution
- camera execution
- lighting execution
- technical image generation

The purpose is:

Emotional Meaning
↓
Visual Interpretation

NOT:

Visual Execution

---

# Decision Architecture

Each layer owns a specific decision type.

A layer may influence downstream systems.

A layer must NOT directly execute downstream decisions.

| Layer                   | Decision Type            |
|-------------------------|--------------------------|
| Campaign Brief          | Campaign Definition      |

# Visual Intent System

Define the emotional-perceptual objective of the image.

NOT: Execution Mechanics

**Examples**
- Intimacy
- Belonging
- Discovery
- Momentum
- Progression
- Calm capability
- Empowerment
- Freedom
- Human warmth
- Quiet confidence
- Protection
- Transformation
- Achievement
- Ease
- Emotional safety

**Rules**
- Visual intent must support narrative meaning.
- Visual intent must remain emotionally recognizable.
- Visual intent should preserve downstream flexibility.
- Visual intent should remain culturally scalable.
- Visual intent should remain compatible with brand identity.

---

# Visual Concept System

Define What kind of image exists

NOT: How the image is executed

**Examples**
- Guided Experience
- Shared Achievement
- Personal Ritual
- Emotional Breakthrough
- Everyday Transformation
- Quiet Observation
- Human Connection
- Mentor Relationship
- Progress Journey
- Environmental Immersion
- Reflective Moment
- Social Encouragement
- Lifestyle Integration

**Rules**
- Visual concepts should emerge from narrative meaning.
- Visual concepts should remain execution-flexible.
- Visual concepts should avoid visual cliché.
- Visual concepts should preserve category compatibility.
- Visual concepts should support emotional readability.

---

# Subject Relationship Logic

Define psychological relationship between the viewer and the scene.

NOT: Physical Placement

You are strictly forbidden from specifying camera mechanics (e.g., lens types, specific focal lengths, camera heights, or angles).

**Examples**
- Guidance
- Support
- Equality
- Aspiration
- Belonging
- Observation
- Discovery
- Encouragement
- Partnership
- Mentorship
- Shared Growth
- Emotional Trust

**Rules**
- Relationships should support narrative meaning.
- Relationships should remain psychologically recognizable.
- Relationship dynamics should remain emotionally coherent.
- Relationships should remain compatible with audience identity.

---

# Perceptual Meaning System

Define the intended psychological interpretation of the image.

NOT: How the image is technically rendered.

Do not map explicit geometric layouts, composition grids, or positional coordinates.

**Examples**
- This feels achievable.
- This feels emotionally safe.
- This feels aspirational but attainable.
- This feels naturally integrated into life.
- This feels calm and confident.
- This feels socially welcoming.
- This feels emotionally supportive.
- This feels modern and frictionless.
- This feels human and authentic.


**Rules**
- Perceptual meaning should remain emotionally clear.
- Meaning should remain compatible with strategic direction.
- Meaning should remain compatible with brand identity.
- Perceptual interpretation should preserve downstream execution flexibility.

---

# Attention Control & Cognitive Load
Define how the viewer's eye should interact with the visual message.

- **Structural Density:** [Low / Medium / High] (e.g., Low for modern minimalism, High for rich lifestyle environments).
- **Focal Priority:** Explicitly state what narrative element or relationship must claim immediate cognitive priority to protect the strategic takeaway.

---

# Distinctiveness System

Actively audit outputs against low-value creative drift. If an anti-pattern emerges, strip it out completely and re-anchor to strategic utility.

**Evaluate**

- Brand recognizability
- Emotional recognizability
- Category differentiation
- Conceptual uniqueness
- Narrative freshness
- Visual memorability

**Avoid**
- Generic lifestyle imagery
- Template-driven visual concepts
- Overused commercial tropes
- Trend imitation without strategic relevance
- Visual cliché
- Emotionally empty aesthetics
